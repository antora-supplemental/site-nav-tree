= Changelog

== 0.2.1 — 2026-08-30

* Flatten Antora's anonymous single-tree wrapper when wrapping component roots (fixes empty expanded carets).
* Unwrap a leading start-page nav item that duplicates the component root title/URL (no Business Bootstrap > Business Bootstrap).
* Ship companion `ui/js/site-nav-tree-current.js` to prefer the deepest `is-current-page` when URLs collide across the forest.

== 0.2.0 — 2026-08-30

* Add `include` allowlist so multi-source hubs can curate the forest without listing every stub in `exclude`.
* When `include` is set and `order` is empty, forest order follows `include`.
* Publish `site.keys.site_nav_tree_include` / `_exclude` / `_order` for breadcrumb alignment.
* Docs: registering a content source ≠ adding a sidebar root.

== 0.1.0 — 2026-08-30

* Initial release: wrap `NavigationCatalog#getNavigation` into a site-wide component forest.
* Keeps default Antora / Valentus `nav-tree` behavior (no UI wipe).
* Optional `order` / `exclude` config; sets `site.keys.site_nav_tree`.
* Companion Valentus `ui/partials/nav-menu.hbs` drops redundant component title line.
